# gh-meta

Standalone CLI and GitHub CLI (`gh`) extension binary crate for
[`gh-meta`](https://github.com/Archont561/gh-meta) — *Your `.github/`
directory, managed as code.*

At this stage the binary is an intentional version-only scaffold exposing
`gh-meta --version`, `-V`, `gh-meta version`, and `--help` before the
full interactive and command workflows (targeting
[`clifacet`](https://github.com/Archont561/clifacet)) are added.
