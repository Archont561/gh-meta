# Regain direction

Use when goals, priorities, or active constraints become uncertain.

1. **Pause.** Stop implementation edits before expanding scope.
2. **Reconstruct.** Inspect working-tree status, `backlog/` tasks and ADRs, recent test runs, and current errors. Separate observed facts from assumptions.
3. **Summarize.** State the current objective, verified state, open gaps, and unknown variables concisely.
4. **Offer a path.** Propose up to three concrete next options, recommending the smallest safe step.
5. **Resume deliberately.** Confirm any ambiguous choice with the user and execute within scope.
